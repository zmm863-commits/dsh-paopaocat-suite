# 🐱 泡泡猫 DSH 插件合集（Paopaocat Suite）

> 一条命令装好全部精选插件，新手开箱即用。
> Install all curated plugins with one command. Zero config, ready to go.

[![npm version](https://img.shields.io/npm/v/dsh-paopaocat-suite?label=npm)](https://www.npmjs.com/package/dsh-paopaocat-suite)

## ✨ 包含插件

| 插件 | 说明 |
|---|---|
| 🎲 [dsh-dice-game](https://www.npmjs.com/package/dsh-dice-game) | 骰子大作战 — 吹牛、猜红点、猜红蓝等 6 种玩法 |
| 📎 [dsh-paperclip](https://www.npmjs.com/package/dsh-paperclip) | 文件上传回形针 — 一键上传文件到输入框 |
| 🐱 dsh-paopaocat-welcome | 新手引导中心 — 首次欢迎卡、功能导航 |
| 🎨 dsh-paopaocat-skin | 泡泡猫皮肤 — 可爱猫咪主题 |

## 🚀 一键安装

```bash
npx @deepseek-ai/dsh plugin --profile web add dsh-paopaocat-suite
```

安装完成后重启 DSH Web，打开即可看到欢迎页面。

## 📦 包含功能

- **新手引导**：首次打开欢迎卡，介绍全部功能
- **骰子游戏**：6 种经典玩法，单人 vs AI
- **文件上传**：回形针按钮，支持拖拽
- **猫咪皮肤**：粉色可爱主题
